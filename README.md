OSINT Starter Repository

A curated starter repo collecting popular OSINT tools and a simple script to clone them into a tools/ folder for quick use.

Quickstart

1. Clone this repo (you're already here in the worktree).
2. Run the clone script to fetch tools:

   bash clone_osint_tools.sh
